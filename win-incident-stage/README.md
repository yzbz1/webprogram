# Windows 事件单前台调度台 (`win-incident-stage`)

基于 Electron 的 Windows 全局置顶悬浮桌面工具，视觉与交互参考 **iPadOS 前台调度（Stage Manager）**：右侧 3D 透视缩略卡片列实时预览待处理事件单，点击任一单据滑出至前台悬浮磨砂卡片进行编辑，并与 **DSH 插件 (`dsh-plugin-incident-drawer`)** 及 **Chrome 扩展 (`chrome-incident-drawer`)** 实时共享同一份配置文件与本地 Excel（`.xlsx`）。

---

## 一、功能特性

- **iPadOS 前台调度（Stage Manager）3D 交互**：
  - **右侧 3D 缩略列表**：屏幕右边缘纵向排列最多 10 张带 3D 透视倾斜与毛玻璃质感的缩略卡（左下角附带状态角标，内部显示精简单号 + 首字段摘要预览）。
  - **悬停聚焦**：鼠标移上右侧某张卡片时平滑扶正并向左探出，展示完整事件单号与两行摘要预览。
  - **前台调度卡片**：点击任意缩略卡后在屏幕中右区域浮现立体玻璃编辑大卡（左边缘支持手动拖拽调宽 `300px–540px`），切换另一张单据时自动平滑替换前台卡片。
- **macOS 红绿灯自定义键盘快捷键**：
  - 顶部状态按钮下方左对齐排列分离式红、黄、绿 3 颗 macOS 快捷圆点，悬停顶部状态区或圆点时展开图标与功能提示，右键任意圆点可直达快捷键配置；默认绑定 `Win+Shift+S` 区域截屏、`Win+D` 显示桌面、`Win+V` 剪贴板历史，支持录制任意组合键或绑定网址 / 本地文件 / 设置 / 待办 / 刷新 / 收起。
- **经典键盘小猫 & 全息前景待办卡片**：
  - 右下角贴边驻留一只紧贴屏幕边缘的经典拍键盘小猫（悬停/点击时小猫保持原地不动，键盘区紧凑收缩，双爪随全局按键敲击 `← ↑ ↓ →` / `R` / `ctrl` / `shift` 键帽）。
  - 小猫面前直接嵌入一张与上方事件单风格一致、但带有**科幻全息投影质感**的 3D 待办小卡片（显示当前待办条文，按设定间隔自动轮播）；**点击小卡或小猫**即可在屏幕中右区域滑出与事件单同等尺寸的**透明全息待办屏幕**，支持增删、勾选完成及置顶展示某条待办。
- **琉璃光弧悬浮球音乐播放器（播放显示专辑封面）**：
  - 最右下角悬浮一颗高光琉璃光弧水滴球（待机/暂停呈现深邃曜黑×液态银彩光交界线）；鼠标移开时**缩小为精致小球**，鼠标放上去时**顺滑放大并绽放黑洞引力光环与吸积盘光晕**，同时**左侧出现上一首、右侧出现下一首**按钮；**播放时自动展示歌曲专辑封面**。
  - **左键点击球体**播放或暂停，**右键点击球体**选择/打开本地音乐文件夹（自动解析 MP3 内嵌或目录 `cover` 专辑封面；留空时自动衔接 Windows 系统媒体控制 SMTC）。关闭小猫或播放器开关时**立即释放对应监听与后台进程，零额外性能消耗**。
- **空白区域完全鼠标穿透**：
  - 除可见卡片、控制条、快捷点、小猫与球形播放器外，屏幕其余所有区域点击、滚轮和键盘事件**直接穿透给底层的微信、浏览器、IDE 或 Excel**。
- **三端实时共享同一份 Excel & 多屏托盘**：
  - 共用 `$DSH_HOME/incident-drawer-config.json`（未设置 `DSH_HOME` 时为 `~/.dsh/incident-drawer-config.json`）。
  - 托盘右键与设置弹窗均支持一键**显示/隐藏键盘小猫**、**显示/隐藏球形播放器**、切换显示器、深浅色磨砂主题、全局置顶与 `Alt + Shift + E` 一键收起。

## 二、安装与启动方式

### 方式 1：绿色便携版（推荐公司内网免环境部署）

构建后会生成独立绿色文件夹 `release/win-incident-stage-portable/`，**不依赖 Node.js，不写注册表**，直接整个文件夹拷贝到公司内网电脑即可运行：

1. 直接双击 `release/win-incident-stage-portable/IncidentStage.exe`（或根目录的 `start-desktop-silent.vbs` / `start-desktop.bat`）。
2. 启动后屏幕右边缘即出现 3D 缩略卡片，Windows 右下角系统托盘也会出现蓝白调度图标。

### 方式 2：开发/源码目录启动

```bash
npm install
npm run build
npm start
```

或直接双击项目根目录的 [start-desktop-silent.vbs](start-desktop-silent.vbs)（静默无黑框启动）或 [start-desktop.bat](start-desktop.bat)。

### 重新打包绿色便携版

```bash
npm run typecheck
npm run build
npm test
npm run pack:portable
```

打包产物输出在 `release/win-incident-stage-portable/IncidentStage.exe`。

## 三、使用方式

1. **绑定共享 Excel 与开关桌面挂件**：点击顶部控制条 **`⚙`**（或右键系统托盘图标）打开设置，可切换「表格与挂件」「红绿灯快捷」「待办提醒」三个分页，分别配置共享 `.xlsx`、开关小猫/播放器、自定义 3 颗快捷圆点动作以及管理每小时轮播的待办清单。
2. **编辑事件单与超链接跳转**：
   - 悬停右侧 3D 缩略卡预览单号与摘要，点击即可调度至前台大卡编辑；
   - 点击前台卡右上角 **`打开`** 跳转到第 1 列超链接，失焦自动写回并带外部更新防覆盖提醒。
3. **小猫与球形播放器**：
   - 右下角键盘小猫原地驻留并随全局按键拍打键盘，面前悬浮全息待办小卡；点击小卡或小猫即可在前台展开透明全息待办屏幕，支持增删、勾选与置顶展示；
   - 鼠标悬停最右下角的琉璃光弧悬浮球，球体平滑放大并绽放黑洞光晕，左侧出现上一首、右侧出现下一首按键；左键播放/暂停，右键选择本地音乐文件夹（留空自动联动 Windows SMTC）。
4. **快速隐藏/呼出**：按全局快捷键 **`Alt + Shift + E`**、点击顶部 **`»`** 或左键单击右下角系统托盘图标即可贴边收起/恢复（贴边隐藏后也会自动暂停小猫与播放器监听）。

## 四、目录结构

```text
win-incident-stage/
├── start-desktop.bat         # 便携启动脚本
├── start-desktop-silent.vbs  # 无黑框静默启动脚本
├── assets/                   # 托盘与窗口图标
├── dist-app/                 # 预编译好的 Electron 主进程、media-helper.ps1 与渲染器产物
├── sample/incidents.xlsx     # 兜底示例 Excel
├── scripts/
│   ├── build.mjs             # esbuild 构建、media-helper 复制与图标生成
│   ├── pack-portable.mjs     # 打包离线绿色版 IncidentStage.exe（含 koffi win32 扩展）
│   └── test-stage.mjs        # 三端 Excel 共享同步与构建产物测试
└── src/
    ├── shared/types.ts       # IPC、快捷圆点、待办、媒体与输入状态类型契约
    ├── main/                 # Electron 主进程、Win32/输入监听、SMTC 媒体桥、Excel 引擎与托盘
    └── renderer/             # Stage Manager 3D 界面、键盘小猫与 Siri 水滴球播放器
```
