# SafeMover · 防掉盘渐进式安全搬运助手

专为老旧 U 盘 / SD 卡 / 移动硬盘设计的本地渐进式文件搬运工具：自动监测移动存储空间，有空间就「一点一点」搬运，绝不直接 Move，全流程校验防掉盘不丢文件。

## 核心特性

- **原子五步安全搬运**：空间预检 → 平稳限速写入 `.safemove.part` → `fsync` 强制落盘 → 从移动设备回读 `SHA-256` 校验 → 原子改名后再删除（或移入回收站）PC 源文件。
- **老旧设备防掉盘保护**：单线程串行、令牌桶限速（默认 `10 MB/s`）、单文件冷却歇息、累计写入深度降温散热、保留安全余量防止塞满损坏分区。
- **智能空间感知 & 掉盘自愈**：空间不足自动待命，腾出空间即刻续搬；支持「见缝插针」先搬较小文件；掉盘立刻保护 PC 源文件，按盘符 + 卷标自动识别重连并清理残缺 `.part` 文件。
- **零第三方依赖**：纯 Node.js 原生实现，启动即用，配置保存在 `config.json`，每次搬运均写入 `transfer.log.jsonl` 哈希审计记录。

## 目录结构

```text
safe-usb-mover/
├── server.mjs                      # 零依赖 Node.js 搬运引擎、磁盘监测与 HTTP/SSE 服务
├── public/
│   └── index.html                  # 本地 Web 控制台界面
├── 启动-安全搬运助手.bat             # 双击启动服务并自动打开浏览器
├── 停止-安全搬运助手.bat             # 一键停止端口 3005 后台服务
├── 开机静默启动-安全搬运助手.vbs      # 无窗口后台静默启动（可创建快捷方式放入开机启动项）
├── config.json                     # 运行后自动保存的用户配置
└── transfer.log.jsonl              # 每次校验通过的搬运审计日志
```

## 环境要求

- Windows 10 / 11
- Node.js 18+（推荐 Node.js 20+ / 24）

## 快速启动

1. **双击启动**（推荐）：直接双击本项目目录下的 `启动-安全搬运助手.bat`，会自动启动服务并打开控制台 `http://127.0.0.1:3005/`；需要停止时双击 `停止-安全搬运助手.bat`。
2. **命令行启动**：
   ```powershell
   cd d:\WorkSpaceAi\webprogram\safe-usb-mover
   node server.mjs
   ```
   然后浏览器访问 `http://127.0.0.1:3005/`。
3. **开机静默后台运行**：右键 `开机静默启动-安全搬运助手.vbs` 创建快捷方式，按 `Win + R` 输入 `shell:startup` 打开启动文件夹，把快捷方式拖进去即可。
